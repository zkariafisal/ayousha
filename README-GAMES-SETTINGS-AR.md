# تحديث إعدادات الألعاب الجديدة

- أصبحت الألعاب الخمس تعرض شاشة إعدادات قبل بدء اللعب، على غرار لعبة الترفيه والخداع.
- يمكن تحديد عدد الجولات (3 أو 5 أو 10 أو 15) وطريقة اختيار الأسئلة (حسب ترتيب البنك أو عشوائياً).
- تُحفظ التفضيلات على الجهاز وتُكتب إعدادات عدد الجولات ونمط الاختيار في غرفة اللعبة عند بدء المباراة.
- أضيف شرح طريقة اللعب قبل البدء، مع إبقاء الشرح داخل واجهة الجولة.
- يمنع بدء جولات تتجاوز العدد المحدد في الألعاب التي تستخدم زر الجولة التالية.
- تم فحص صياغة ملفات JavaScript المستقلة والشفرة المضمنة في index.html، والتأكد من وجود ملفات JavaScript المحلية المشار إليها.
- لم يُجر اختبار حيّ لخدمة Firebase أو اللعب من جهازين؛ يعتمد ذلك على إعدادات قاعدة البيانات والاستضافة.
