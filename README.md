# تطبيق زكريا وعيوشة 💕
### تواصل مباشر فوري وألعاب زوجية ورومانسية

تطبيق تواصل وألعاب تفاعلي حقيقي يربط بين زكريا (حبيبي) وعيوشة في هاتفها مباشرة عبر قاعدة بيانات Firebase Realtime ونظام إشعارات الدفع الفورية (FCM Push Notifications).

---

## 📱 آلية الربط المباشر بين الهاتفين:
- **تطبيق زكريا (هذا التطبيق):** يعمل بدور `me` (حبيبي)، وأي رسالة، صورة، تسجيل صوتي، حركة لعبة، أو نبضة حب تُرسل فوراً إلى عيوشة `her`.
- **تطبيق عيوشة (المثبت في هاتفها):** يعمل عبر الرابط: `https://ayousha.vercel.app/?for=her`
- **حالة الاتصال المباشر:** تظهر حالة هاتف عيوشة فورياً (متصلة الآن 🟢 / آخر ظهور / تكتب الآن... ✍️).
- **إشعارات الهاتف (FCM):** حتى لو كان هاتف عيوشة مغلقاً أو التطبيق في الخلفية، يرسل التطبيق إشعار Push حقيقي لهاتفها المسجل، والضغط على الإشعار يفتح التطبيق مباشرة في هاتفها.

---

## 🎮 الألعاب والمميزات المتضمنة:
1. **لعبة الترفيه والخداع (Trivia & Bluffing):** نظام الـ 4 خيارات لاكتشاف الحقيقة من التمويه.
2. **ارسم وخمّن (Draw & Guess):** رسم مباشر وتخمين متبادل.
3. **خمن الرقم السري (Secret Number):** مبارزة وتخمين بالدور مع إشعارات.
4. **افتح الباب الصحيح (Open the Door):** تناوب فتح الأبواب واكتشاف الجوائز.
5. **اختر رقماً / كروت القلوب (Heart Cards):** رسائل ومفاجآت رومانسية.
6. **تحدي التخاطر (Telepathy):** معرفة مدى توافق الأفكار.
7. **عجلة الحظ (Romantic Wheel):** مهام وأحكام رومانسية ممتعة.
8. **سؤال اليوم المشترك:** 30 سؤالاً يومياً يظهر جواب الطرفين معاً.
9. **الشات السريع المدمج:** إرسال رسائل عائمة فوق أي لعبة تختفي بعد 5 ثوانٍ دون إيقاف اللعب.
10. **الشات الكامل المطوّر:** رسائل فورية، صور، صوتيات، ردود مقتبسة، تفاعلات بالإيموجي، ورسائل مثبتة.
11. **نبضات الحب (أنا أفكر فيكِ الآن 💗):** تنبيه فوري ونبضة في قلب هاتفها.
12. **عالمنا المشترك / الذكريات ومتابعة المزاج اليومي.**

## 🚀 طريقة التشغيل:
### 1. التشغيل المحلي / التطوير:
```bash
npm install
npm run dev
```
يفتح التطبيق على: `http://localhost:3000`

### 2. البناء للإنتاج:
```bash
npm run build
```
المخرجات تكون في مجلد `dist/`.

### 3. النشر على Vercel أو أي استضافة:
الملف `vercel.json` ومجلد `api/notify.js` مهيأة وجاهزة للنشر المباشر.
