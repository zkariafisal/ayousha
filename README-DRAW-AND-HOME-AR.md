# تحديث الرسم والتخمين وأسئلة الرئيسية
- في الرسم والتخمين: يرسم صاحب الدور، يرسل الرسم، ويخمن الطرف الآخر مرة واحدة فقط.
- تظهر نتيجة صح/خطأ والإجابة الصحيحة والرسم للطرفين، ثم يضغط المخمّن «الآن دورك للرسم» لينتقل الدور إليه.
- تظل دردشة اللعبة كما كانت.
- `random-questions.js`: أسئلة زر «سؤال عشوائي» في الرئيسية.
- `know-me-questions.js`: أسئلة زر «كم تعرفني؟» في الرئيسية.
- يمكنك إضافة أسئلة أخرى إلى المصفوفتين مباشرة.
- اختبار المزامنة الفعلية بين جهازين يتطلب تشغيل المشروع على Firebase.
