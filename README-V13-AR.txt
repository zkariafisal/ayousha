Ayousha V13 — تحديث الألعاب الثنائية والتفاعل اللحظي المشترك

الميزات الجديدة في نظام الألعاب (عالمنا نلعب):
1. قصة نكتبها معًا:
   - نظام تبادل أدوار صارم (Turn-based): لا يمكن لأحد الطرفين كتابة جملة جديدة إلا بعد أن يكتب الطرف الآخر جملته.
   - إشعار فوري وتلقائي عبر Firebase مع نص الجملة الجديدة للطرف الآخر ليقوم بدوره.
   - إضافة نقاط القلوب المشتركة مع كل جملة تُكتب.

2. لعبة XO المشتركة مع شات ذاتي التدمير (5 ثوانٍ):
   - متزامنة بالكامل وبشكل حي بين الهاتفين (❌ لزكريا و ⭕ لعيوشة).
   - إتاحة المحادثة السريعة أثناء اللعب داخل شاشة اللعبة نفسها دون الخروج منها.
   - الرسالة تظهر في فقاعة تفاعلية وتختفي تلقائياً بعد 5 ثوانٍ.

3. حل اللغز المشترك:
   - يكتب الطرف الأول حله بسرية تامة دون كشفه.
   - ينتظر النظام إجابة الطرف الثاني، وعند تقديم الإجابتين يتم الكشف عنهما ومقارنتهما مع الإجابة النموذجية.
   - مكافأة القلوب المشتركة تلقائياً بحسب صحة الحل.

4. ألعاب جديدة مضافة:
   - تخاطر القلوب (Telepathy): اختيار سري لخيارات يومية ورومانسية لمعرفة هل تفكران في نفس الشيء.
   - عجلة التحديات والرومانسية: دوران تفاعلي لمهام حب ممتعة ومتبادلة.
   - ربط رصيد القلوب والأوسمة بقاعدة بيانات Firebase Realtime وتحديثها حياً.
