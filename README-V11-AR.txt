Ayousha V11 — تحسين تنبيهات الخلفية

تم الحفاظ على ميزات V10 وتعديل خيارات إشعار نظام Android، وإعادة تسجيل رمز FCM عند العودة للتطبيق، وتحسين تنبيه غياب مفتاح VAPID.

مهم: لا يمكن لصفحة ويب تشغيل صوت JavaScript بعد إغلاقها. صوت الإشعار يأتي من نظام Android/Chrome عبر FCM، ولا يمكن ضمان نغمة مخصصة أو وصول فوري في كل وضع توفير بطارية.

إعدادات مطلوبة:
1. Vercel: FIREBASE_SERVICE_ACCOUNT صحيح.
2. داخل إعدادات البرنامج: VAPID key الخاص بـ Firebase Cloud Messaging.
3. على كل هاتف: تفعيل إذن إشعارات الموقع في Chrome، وإشعارات Chrome مع الصوت، وإلغاء تقييد البطارية إذا كان يمنع الإشعارات.
4. افتح التطبيق على الهاتفين بعد النشر وفعّل الإشعارات.
5. اختبر من هاتف إلى الآخر بينما Chrome بالخلفية والشاشة مقفلة.

القيود: التطبيق يخزن رمز FCM واحدًا لكل دور (me/her)، لذا آخر جهاز يسجل الدور يستبدل رمز الجهاز السابق. لا تعمل الإشعارات عند إيقاف الهاتف تمامًا أو انقطاع الإنترنت.

تنبيه أمني: واجهة /api/notify تحتاج مصادقة وحدود معدل طلبات قبل استخدامها على نطاق عام، كما ينبغي حماية قواعد Firebase وعدم الاعتماد على ?for=me/her كوسيلة تسجيل دخول.
